# Destatis Municipal Directory Extractor (GV3Q)

This script processes the official Excel file **`AuszugGV3QAktuell.xlsx`** provided by the Federal Statistical Office of Germany (Destatis) and exports all German municipalities and cities (record type / Satzart 60), cleaned and enriched with regional metadata, to **JSON** and **CSV**.

https://www.destatis.de/DE/Themen/Laender-Regionen/Regionales/Gemeindeverzeichnis/_inhalt.html

## Included Fields

| Field         | Type        | Description                                                                 | Example                |
| ------------- | ----------- | --------------------------------------------------------------------------- | ---------------------- |
| `ars`         | String (12) | Official Regional Key (State + Admin District + District + Assc + Mun)      | `"010010000000"`       |
| `state`       | String      | Name of the federal state                                                   | `"Schleswig-Holstein"` |
| `district`    | String      | Name of the rural district (Landkreis) or urban district (kreisfreie Stadt) | `"Flensburg, Stadt"`   |
| `name`        | String      | Official municipality name                                                  | `"Flensburg, Stadt"`   |
| `postal_code` | String (5)  | 5-digit postal code of the administrative headquarters                      | `"24937"` or `"01067"` |
| `population`  | Integer     | Population count (based on the 2022 Census)                                 | `95568`                |
| `area_km2`    | Float       | Cadastral area in km²                                                       | `56.73`                |
| `latitude`    | Float       | Geographic latitude of the centroid                                         | `54.78252`             |
| `longitude`   | Float       | Geographic longitude of the centroid                                        | `9.43751`              |

## Prerequisites

- Python 3.8+ (or `py` on Windows)
- Dependencies in `requirements.txt`

Installation:

```bash
pip install -r requirements.txt
```

## Usage

### Default Export (JSON & CSV)

```bash
python main.py
```

Generated by default:

- `german_municipalities.json` (~2.7 MB, formatted in UTF-8)
- `german_municipalities.csv` (~1.0 MB, with UTF-8-BOM for seamless opening in MS Excel)

### Advanced Options

```bash
# Only inhabited municipalities (filters out uninhabited unincorporated areas)
python main.py --inhabited-only

# Additional attributes (AGS, gender breakdown m/f, density, travel area, urbanization)
python main.py --include-extra

# Compact JSON without indentation (saves disk space)
python main.py --compact-json

# Specify custom file paths
python main.py -i AuszugGV3QAktuell.xlsx -j my_export.json -c my_export.csv

# Use semicolon as CSV delimiter
python main.py --csv-delimiter ";"
```
